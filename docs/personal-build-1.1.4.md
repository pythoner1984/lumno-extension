# Lumno 1.1.4 定制版

本版本以原作者 main 的 82446df53a69d773d793a8682a39dcc9b42fc279 为基线。
上游 PR #75 已合并，但只采纳了其中部分功能。本分支继续保留个人定制功能。

- 站点卡片保留“最近访问 / 最常访问 / 自定义”。自定义列表可增删、编辑、排序和分页，兼容旧版保存的数据。
- 新增快捷方式可搜索并选择浏览器书签；书签原内容不变。
- 三种书签视图和嵌套菜单均有图钉入口。已添加的网站显示实心图钉，避免重复添加。
- 每日句子沿用新版上游的 TXT / MD 导入，一条非空内容行作为一句。
- 关闭其他标签页前可明确取消或确认，取消按钮默认获得焦点。
- 外观面板可独立调节搜索框和快捷图标底衬透明度。0% 保留原底色，100% 完全透明，文字和图像保持清晰；重置恢复原样。
- 透明度兼容新版普通、磨砂和流体玻璃样式；展开的搜索菜单保留可读底色。

构建命令使用 Node.js 22：`npm ci`、`npm run check`、`npm test`、`npm run package:store`。

Ego 验证使用现有扩展的加载位置，更新前另存完整目录备份。安装包保存在独立的 1.1.4 定制版目录。

## 验证

- 255 组脚本测试、56 个文件中的 479 项 React 测试通过。
- JavaScript 语法、未定义变量、TypeScript、资源完整性、四种语言文案及安装包检查通过。
- 在 Ego 中原位加载本定制版，保留原扩展 ID，实测三种书签视图及嵌套图钉、收藏夹选择器、自定义网站增删编辑排序、TXT/MD 按行导入。
- 实测透明度独立保存、键盘调节、重置和刷新恢复；检查普通、亚克力及液态玻璃，桌面和 390px 窄屏。
- 在独立测试窗口实测取消、Esc 和确认关闭；确认普通测试标签页关闭，当前、置顶和分组页保留。
- 测试结束恢复原设置和句库，只删除本次创建的临时书签与快捷方式。
